## Что считается архитектурным решением

Решение, которое затрагивает несколько частей системы, трудно обратимо или влияет на атрибуты качества. Остальное решается в коде и в ревью.

## Как добавить запись

1. Взять следующий свободный номер — номера не переиспользуются
2. Скопировать форму из [`docs/templates/adr.md`](../templates/adr.md)
3. Заполнить; рассмотренных вариантов — не меньше двух, с доводами за и против у каждого
4. Добавить строку в эту таблицу
5. Отправить запросом на слияние; второй участник подтверждает решение в ревью, после чего статус меняется на «принято»
