# Ресурсы и операции REST

Перечень операций **до** описания OpenAPI (ЛР 4Б) и до кода. Каждая операция следует из требования в [requirements.md](../requirements.md); коды ответов — из критериев приёмки. Все пути начинаются с `/v1`, кроме `/health`.

**Роли**: «открыто» — без входа; `buyer` — вошедший покупатель; `admin`, `seller` — сотрудник пекарни из пути запроса; «владелец» — покупатель, создавший бронь. Обращение к чужой брони или к данным чужой пекарни отвечает `404`, как к несуществующей (`NFR-02`).

**Формат ошибки** — `application/problem+json` по RFC 9457: тип, заголовок, код, пояснение и поля с ошибками для `422`. Подробно — в ЛР 4Б.

## Решения

**Отмена покупателем и отмена пекарней — две операции, а не одна.** Различаются не только автором. У покупателя — правило времени (до начала окна) и возврат остатка; у пекарни — причина, уведомление и остаток не возвращается. Права проверяются по-разному: покупатель — владелец брони, сотрудник — по пекарне из пути. В модели это разные события (`BookingCancelled`, `BookingCancelledByBakery`). Один обработчик с ветвлением по роли собрал бы два разных правила в одном месте; две операции держат каждое правило рядом со своей проверкой прав.

**Выдача — ресурс «выдача» по коду в пределах пекарни, а не действие над бронью по идентификатору.** Продавец знает код, который назвал покупатель, а не идентификатор брони. Путь `bakeries/{bakery_id}/pickups` сразу ограничивает поиск своей пекарней (`AC-05.7`): код другой пекарни не находится по построению.

**Поиск рядом — по координатам; адрес — отдельный ресурс `places`.** Так время внешней службы координат не входит во время ответа списка (`К-1`, `NFR-01`), а координаты запоминаются на устройстве покупателя (`AC-02.7`).

**Повтор отмены — `200` с той же отменой, повтор выдачи — `409`.** Отмену повторяет тот же покупатель с другого устройства — ему нужен результат, а не ошибка. Выдачу повторяет другой сотрудник — ему нужно знать, что набор уже отдан и кем (`AC-05.5`).

**Заведение пекарни без HTTP-операции.** Пекарни заводит команда (`C-11`); открытая операция для этого — лишняя поверхность атаки, которой пользовались бы раз в месяц. Команда в контейнере `api` проверяет те же правила, что и агрегат `Bakery`.
